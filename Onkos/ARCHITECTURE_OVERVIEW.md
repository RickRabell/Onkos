## Principios de Diseño Aplicados

### 1. **Separación de Responsabilidades**
```
? BAD: DCCCameraController renderiza la grilla
? GOOD: GridSystem se encarga de renderizar
         DCCCameraController solo controla cámara
         GUI orquesta ambos
```

### 2. **Inyección de Dependencias**
```cpp
// ? GOOD: GridSystem no conoce BaseApp
drawViewportPanel(..., GridSystem* gridSystem) {
    if (gridSystem) gridSystem->renderGrid(...);
}

// ? BAD: Sería acoplamiento circular
class GridSystem {
    BaseApp* m_baseApp;  // Acoplamiento tight
};
```

### 3. **Funciones Puras para Transformaciones**
```cpp
// ? GOOD: Sin efectos secundarios, determinístico
EU::Vector3 snapPosition(const EU::Vector3& pos) const;
// Mismo input ? mismo output, siempre

// ? BAD: Estado mutable, efectos secundarios
void snapActor(Actor* actor);  // Modifica actor directamente
```

### 4. **Null Checks Defensivos**
```cpp
// ? GOOD: Previene crashes si puntero nulo
if (gridSystem) {
    gridSystem->renderGrid(...);
}

// ? BAD: Crash si gridSystem es nullptr
gridSystem->renderGrid(...);  // Undefined behavior
```

```
Punto de integración: BaseApp::update()

FLUJO PROPUESTO:
1. Si LEFT CLICK detectado
2. Castear rayo desde cámara a través de mouse
3. Encontrar intersección más cercana con mesh
4. Seleccionar actor y aplicar snap si activo
5. Actualizar inspector y outliner

CÓDIGO PSEUDOCÓDIGO:
if (ImGui::IsMouseClicked(ImGuiMouseButton_Left)) {
    Ray ray = camera.getRayFromScreenPoint(mouseX, mouseY);
    Actor* hitActor = sceneGraph.raycast(ray);
    if (hitActor) {
        gui.selectedActorIndex = findIndex(hitActor);
        if (gridSystem.isSnapEnabled()) {
            // Aplicar snap a transformación
            auto pos = hitActor->getTransform()->getPosition();
            hitActor->getTransform()->setPosition(gridSystem.snapPosition(pos));
        }
    }
}
```

### Integración con TransformCommand

```
ACTUAL: TransformCommand modifica transformación directamente

PROPUESTO CON SNAP:
1. User mueve gizmo
2. TransformCommand calcula nueva posición
3. Si gridSystem.isSnapEnabled():
   newPos = gridSystem.snapPosition(newPos)
4. Aplica transformación
5. Guarda en undo/redo

CÓDIGO:
void TransformCommand::execute() {
    if (gridSystem && gridSystem.isSnapEnabled()) {
        m_position = gridSystem.snapPosition(m_position);
        m_rotation = gridSystem.snapRotation(m_rotation);
        m_scale = gridSystem.snapScale(m_scale);
    }
    actor->setTransform(m_position, m_rotation, m_scale);
}
```

```cpp
    EU::Vector3 output = grid.snapPosition(input);

    EXPECT_EQ(output.y, 1.5f);

    controller.update(10, 0, true, false, 0, false);  // Right drag
```

## Conclusión

La arquitectura implementa:
- ? Separación clara de responsabilidades
- ? Bajo acoplamiento (GridSystem independiente)
- ? Fácil extensibilidad (para picking, snap automático)
- ? Robustez contra nullptrs y edge cases
- ? Performance reasonable (proyecciones solo si necesario)
