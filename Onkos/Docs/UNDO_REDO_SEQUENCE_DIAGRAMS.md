## 4. Secuencia: Múltiples Operaciones (Undo x N)

```
Inicial: empty undoStack, empty redoStack

Operación 1: Move Object
  Result: undoStack = [MoveCmd], redoStack = []

Operación 2: Rotate Object
  Result: undoStack = [MoveCmd, RotateCmd], redoStack = []

Operación 3: Scale Object
  Result: undoStack = [MoveCmd, RotateCmd, ScaleCmd], redoStack = []

User: Ctrl+Z (Undo 1)
  undoStack = [MoveCmd, RotateCmd]
  redoStack = [ScaleCmd]
  (Escala se revierte)

User: Ctrl+Z (Undo 2)
  undoStack = [MoveCmd]
  redoStack = [ScaleCmd, RotateCmd]
  (Rotación se revierte)

User: Ctrl+Z (Undo 3)
  undoStack = []
  redoStack = [ScaleCmd, RotateCmd, MoveCmd]
  (Movimiento se revierte)

User: Ctrl+Y (Redo 1)
  undoStack = [MoveCmd]
  redoStack = [ScaleCmd, RotateCmd]
  (Movimiento se reaplica)

User: Nueva Operación: Rotate Again
  Result: undoStack = [MoveCmd, RotateCmd2], redoStack = []
  (Nota: redoStack se limpió automáticamente)
```

## 5. Flujo de Ejecución de Comando

```
executeCommand(command)
        ?
        ??? command->execute()
        ?   ??? Aplica cambios
        ?
        ??? m_undoStack.push(command)
        ?   ??? Guarda para undo
        ?
        ??? while (m_redoStack.empty() == false)
        ?   ??? m_redoStack.pop()  [Limpia redo]
        ?
        ??? if (m_undoStack.size() > m_maxHistorySize)
            ??? m_undoStack.pop()  [Limpia historial antiguo]
```

## 6. Estado de las Pilas (Ejemplo Real)

```
Timeline de Usuario:

1. Abre escena vacía
   undoStack: []
   redoStack: []

2. Crea Actor "Cube"
   undoStack: [CreateCmd(Cube)]
   redoStack: []

3. Mueve Cube a (5, 0, 0)
   undoStack: [CreateCmd(Cube), MoveCmd(5,0,0)]
   redoStack: []

4. Rota Cube 45 grados
   undoStack: [CreateCmd(Cube), MoveCmd(5,0,0), RotateCmd(45°)]
   redoStack: []

5. Presiona Ctrl+Z
   undoStack: [CreateCmd(Cube), MoveCmd(5,0,0)]
   redoStack: [RotateCmd(45°)]
   ? Cube sin rotación

6. Presiona Ctrl+Z
   undoStack: [CreateCmd(Cube)]
   redoStack: [RotateCmd(45°), MoveCmd(5,0,0)]
   ? Cube en (0, 0, 0) y sin rotación

7. Presiona Ctrl+Y
   undoStack: [CreateCmd(Cube), MoveCmd(5,0,0)]
   redoStack: [RotateCmd(45°)]
   ? Cube en (5, 0, 0) nuevamente

8. Escala Cube a 2x
   undoStack: [CreateCmd(Cube), MoveCmd(5,0,0), ScaleCmd(2x)]
   redoStack: []  ? Automáticamente limpiado
   ? Cube a escala 2x
   ? Nota: RotateCmd se perdió del redoStack
```

## 8. Comparación de Vectores (Epsilon)

```

epsilon = 0.0001f

?? X: |1.0000 - 1.0001| = 0.0001 ? epsilon ? IGUAL
?? Y: |2.0000 - 2.0000| = 0.0000 ? epsilon ? IGUAL
?? Z: |3.0000 - 3.0000| = 0.0000 ? epsilon ? IGUAL

Resultado: No crear comando (cambios insignificantes)

?????????????????????????????????????

Comparación por componente:
?? X: |1.0 - 5.0| = 4.0 > epsilon ? DIFERENTE ?
```
