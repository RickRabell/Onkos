Enumerator

Alpha 

Standard transparency (Src * Alpha + Dest * (1 - Alpha))

Additive 

Used for fire/magic (Src * 1 + Dest * 1)

PremultipliedAlpha 

Advanced blending where RGB is pre-multiplied by Alpha.
