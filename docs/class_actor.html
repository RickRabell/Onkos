Detailed Description

Represents a renderable entity in the game world.

Author
Ricardo Rabell
Date
2025-11-27

The Actor class inherits from Entity (providing position/rotation/scale) and adds visual capabilities. It manages one or more meshes, materials (textures), and the corresponding GPU buffers (Vertex/Index). It also handles its own rendering logic, including shadow mapping support.

Called when the actor is awakened in the scene.
