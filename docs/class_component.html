Detailed Description

Abstract base class for all components attached to entities.

Author
Ricardo Rabell
Date
2025-11-21

In the Entity-Component System (ECS), a component represents a modular piece of data or logic (e.g., a Mesh, a Script, a Transform). This interface enforces the lifecycle methods that all components must implement.
