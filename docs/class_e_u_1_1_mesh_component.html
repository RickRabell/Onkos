Detailed Description

Componente de malla que contiene información de geometría.

Esta clase almacena los vértices e índices necesarios para representar una malla 3D, así como métodos básicos para inicialización, actualización, renderizado y destrucción.

Nota: Actualmente no hereda de una clase Component, pero está preparado para ello.
