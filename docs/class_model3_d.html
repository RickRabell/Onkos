Detailed Description

Represents a 3D model resource.

Author
Ricardo Rabell
Date
2025-11-20

This class inherits from IResource and is responsible for loading, parsing, and storing 3D geometry data. It specifically integrates the Autodesk FBX SDK to handle complex model hierarchies, meshes, and material data.
