Detailed Description

Manages the position, rotation, and scale of an entity.

Author
Ricardo Rabell
Date
2025-11-27

The Transform component is fundamental for 3D rendering. It stores spatial data and computes the World Matrix (SRT Matrix) used to position the entity in the 3D world relative to the origin.
