Detailed Description

Manages the Immediate Mode GUI (ImGui) system for the engine.

Author
Ricardo Rabell
Date
2025-12-05

This class handles the initialization, updating, and rendering of the editor's user interface tools using the Dear ImGui library. It acts as a bridge between the engine's data (like Actors and Components) and the visual editor controls. It is responsible for drawing widgets, property inspectors, and handling user input for the UI layer.
